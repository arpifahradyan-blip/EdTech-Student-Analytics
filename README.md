# 🎓 EdTech Student Analytics & Performance Tracker

An analytical toolset built with **Python**, **Matplotlib**, and **NumPy** to process student performance metrics, track study sessions, and generate clear visual reports on core competencies.

---

## 📊 Key Features

- **Soft Skills Assessment:** Generates publication-ready bar charts evaluating essential student competencies (Problem Solving, Critical Thinking, Time Management, Adaptability, etc.).
- **Session & Performance Logger:** Tracks study durations, attendance trends, and engagement metrics.
- **Automated Export:** Exports high-resolution visual charts (`.png`) for integration into EdTech reports.

---

## 🛠️ Tech Stack

- **Language:** Python 3.x
- **Data Analysis & Visualization:** `matplotlib`, `numpy`
- **Version Control:** Git & GitHub
